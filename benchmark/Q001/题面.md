# Q001 前哨仓库 · 修复有缺陷的图

> 这一页连同 `题图.json` 和 `AI_MAP_KIT.md` 一起交给被测的 AI。不要给它 `出题说明.md`、`参考答案.json` 和 `question.json`。

## 背景

这是一张单层的小型搜打撤关卡，45 米主线，5 个房间：

入口门厅 → 前厅 → 回廊 → 精英厅（撤离点在最深处）；前厅北侧另有一间可选的侧室。

设计意图是三句话：

1. **先易后难**：前厅是第一场战斗，用两名普通敌人热身；全图最强的一场在精英厅。
2. **高潮前喘口气**：回廊里没有敌人，玩家在这里整备，并从门口预先看到精英厅。
3. **绕路有回报**：侧室是可选内容，走进去应该拿得到东西。

## 你的任务

`题图.json` 是一位新人交上来的稿子，里面有若干处问题：有的违反规范，有的不违反规范、但违背了上面的设计意图。

请修复它，输出修复后的完整地图 JSON。

## 约束

- 只输出一份 JSON，不要任何解释文字。
- **所有 ID 保持不变**：不新增、不删除、不改名任何房间、物件、敌人、门、路线。
- `meta.bounds` 不变；房间的形状和位置不变。
- 只改有问题的地方。没有问题的实体，一个字段都不要动。
- 修复后结构校验必须 0 错误、0 告警。
- 在 `meta.designNotes` 里用 3–6 条说明你改了什么、为什么。
